# TapDock — LSPosed 纯模块 · 基础任务栏 Dock

一个**纯 LSPosed（Xposed）模块**：通过 hook SystemUI / 桌面进程，往屏幕顶部任务栏
（系统状态栏）的**布局内部**注入一个**黑色圆角的 Dock 条**——不是悬浮窗，而是任务栏
自身的一部分。


```
状态栏（任务栏）布局内部示意：

┌──────────────────────────────────────────────────┐
│ 通知图标          [▉]               网速 ␣ WiFi ␣ 电量 │  ← 靠右（默认）
│ [▉] 通知图标                       网速 ␣ WiFi ␣ 电量 │  ← 靠左
└──────────────────────────────────────────────────┘
   [▉] = 黑色圆角空 Dock 条（80% 不透明度，12dp 圆角）
```
